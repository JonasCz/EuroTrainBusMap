# Research: bus timetable data for Bosnia & Herzegovina and the Balkans

Status as of **2026-10-19**. Two research passes (no code) looking for current, usable bus timetables for
BiH and neighbours, and for what FlixBus exposes beyond its open GTFS. Re-check URLs and dates before acting:
freshness figures below are what we saw on that day.

**Outcome so far:** added Li-Bus Livno (`ba-livnobus`), Centrotrans (`ba-centrotrans`), the Sarajevo / Mostar /
Banja Luka urban feeds and the `ba-redvoznje` generator (see `docs/data-sources.md`). Nothing from FlixBus beyond
its ODbL GTFS is used. A "routes without timetable" mode is *not* built; it waits on permission from Flix (see §5).

## 2. Websites and aggregators (BiH)

### redvoznje.ba — used (`ba-redvoznje` generator)
- Documented JSON API at `https://redvoznje.ba/api/`: `/api/v1.json`, `/health.json`, `/routes.json`,
  `/routes/{bus|train}/{from}-{to}.json`, `/stations.json`, `/operators.json`, OpenAPI file.
- **CC BY 4.0**, no key, static CDN files, robots `Allow: /`.
- 2,912 city pairs (2,816 bus, 1,147 international), 191 cities (115 in BiH), 50 operators, plus a 4-city urban section.
- Route file shape: `lines[] = {operator, days: "0111111" (Mon..Sun), source, stops: [{name, city, country, time, day_offset, border}]}`,
  `departures[]` with `source_url`. Only 51/100 stations have coordinates.
- Freshness: build of 2026-09-28; `health.json` reported `"status":"degraded"` (source `buskarta-intl` 43 days old at first check).
  No validity dates, only weekday masks.
- Coverage skewed to the Centrotrans-run station boards (Sarajevo, Ilijaš, Visoko, Kakanj, Kiseljak, Olovo, Fojnica)
  + buskarta.ba. E.g. Sarajevo–Banja Luka 19 departures / 12 operators, but Banja Luka–Prijedor 1; Banja Luka–Bihać,
  Bijeljina–Zvornik, Trebinje–Dubrovnik missing.
- Quirk: day masks miss the day the boards were read for buses that had already left (fixed in the generator).

### buskarta.ba = busticket4.me (same platform)
- `www.buskarta.ba` has an expired TLS certificate; bare host works. Sitemap points to busticket4.me (Next.js).
- robots: allows `/`, disallows `/api/` and `/*/search/`; timetable sitemaps empty.
- `sitemap_BA.xml`: 1,620 station departure pages (`/ba/autobuska-stanica/polasci/<slug>?station_id=`), 174 carrier pages
  (Globtour, Croatia Bus, Centrotrans, Autoprevoz Mostar, Lasta, Niš-Ekspres, Trans-Turist, Fudeks, Drita, IDO, Pepeks…;
  heavy overlap with FlixBus marketplace carriers).
- Station pages embed pair lists in Next.js page data (`departure_place_id/name`, `destination_place_id/name`; Sarajevo ≈ 50 destinations).
- `/ba/red-voznje-a-do-b` pages: first/last departure, via towns ("prolazi kroz BORCI, ČELINAC, DOBOJ…"), distance,
  average duration, days, carriers. Exact times only from `/line-details` under `/api/` (robots-disallowed, not called).
- Search URL shape: `/BA/8-206-132-0-0/0-1/Sarajevo-Banja_Luka/21-10-2026`.
- **Terms forbid our use**: "samo za lično korišćenje… zabranjeno… za bilo kakve poslovne, komercijalne ili javne svrhe".

## 3. FlixBus

### Open data (usable)
- `https://gtfs.gis.flix.tech/gtfs_generic_eu.zip` (needs a browser User-Agent; directory listing 403). ODbL
  (transport.data.gouv.fr `tdg-11681`, same file). Last-Modified 2026-10-11, weekly; `feed_info` 20261011–20270411.
  2,103 stops, 1,143 routes, 37,017 trips. Transitous copy identical minus shapes.
- opentransportdata.swiss NeTEx `epip_netex_flixbus_20260511.zip`: same scope (FLIXBUS-eu + FLIXTRAIN-eu, 1,196 lines,
  ~2,285 stops), older.
- Guessed names `gtfs_marketplace_eu`, `_partner_`, `gtfs_eu` → 403. **No public marketplace/partner GTFS.**
- DELFI (DE) has FlixTrain only. MDB / transit.land mirror the flix.tech URL.
- In BiH the GTFS has only Mostar Zapadni, Međugorje, Čitluk, Ljubuški.

### Website / API (not usable without permission)
The website shows ~3,650 European cities because it includes **marketplace partner carriers** that are not in the GTFS.
Endpoints on `global.api.flixbus.com` (CORS `*`, no key), found via the route-map bundle
`vector-map-frontend.cms.flixbus.com/master/manifest.json` → `assets/index-*.js`:

| Endpoint | Returns |
|---|---|
| `GET /cms/cities?language=en-gl&geo_bounding_box={"top_left":{lat,lon},"bottom_right":{lat,lon}}&transportation_category=bus,train,flixtrain&limit=N` | `{result:[{id, uuid, name, country, location:{lat,lon}, slug, search_volume, transportation_category}], count}` — city centroids |
| `GET /cms/cities/{uuid}/reachable?…&currency=EUR` | same + `interconnection` (false = direct), `min_duration`, `avg_duration`, `route_popularity`, price range. No date parameter (= currently bookable) |
| `GET /cms/prices?currency=&departure_city_uuid=` | prices |
| `GET /search/autocomplete/stations?q=…&lang=en` | stations with coordinates + address |
| `GET /search/service/v4/search?from_city_id=…&to_city_id=…&departure_date=dd.mm.yyyy&products={"adult":1}&currency=EUR&locale=en&search_by=cities` | departures per date; legs carry `is_marketplace`, `operator_id`; operators map with legal names |
| `GET /search/service/v2/trip/details?trip=<uid>&locale=en` | ordered stops with times, line code (e.g. `CHR239`), `line_id`, `line_variation_id`, origin/final station, `brand.type:"partner"`. Only the searched stretch: a full line needs origin→final search |
| `/gis/v2/timetable/{station}/departures` | 401 "Missing or invalid api-key" |
| `/cms/lines`, `/cms/stations`, v1/v3 search | 403 "Missing Authentication Token" |

Example trip details: Sarajevo→Belgrade 21 Oct = line CHR3267 (Globtour): Sarajevo 21:00, I. Sarajevo, Foča, Goražde,
Užice, Požega, Čačak, Belgrade 06:15, final station Novi Sad. Sample carriers in Balkan searches (all marketplace):
Centrotrans, Croatia Bus, Transturist Tuzla, Globtour, Trans-Jug, Niš-Ekspres, Fudeks, Drita Travel, IDO Tours, HAK-Komerc, Bisstours.

Website pages: `global.flixbus.com/sitemap/sitemap-v2.xml` → 5,911 `/bus/<city>` pages (schema.org `BusStop` JSON-LD
with coordinates and address, Flix stop UUIDs, "Directly reachable cities" count — Sarajevo 51) and 213,050
`/bus-routes/bus-a-b` pages (min duration, distance, trips/day, first/last departure; no stop lists). No line/timetable pages.

**Legal:** booking terms (`/general-terms-business-and-booking-conditions`) §3.2: "Non-private or commercial use of
the Flix web portal is not permitted. The use of automated systems to extract data from this website for commercial
use ('screen scraping') is prohibited." §3.1: price-comparison sites need a written contract. `shop.flixbus.com`
robots disallows everything; the API host has no robots.txt; the partner API needs a distribution/affiliate agreement
(affiliates via AWIN). The `cms` data has no licence.

- BiH: all 84 cities have a direct link; 1,370 undirected direct pairs touch BiH (Mostar 67, Bugojno 61, Zenica 60,

## 4. National access points and other open feeds
- **Croatia** (promet-info.hr, Hrvatske ceste): only GPP Osijek, HŽPP, Jadrolinija, Pulapromet, ZET — no intercity bus.
  `b2b.promet-info.hr/dc/b2b.gtfs.*` → 401/403, registration needed.
- **Slovenia** (`b2b.nap.si`, CC-BY-SA, already used as `si-nap`): LPP, Nomago, AP Murska Sobota, Arriva, SŽ; 9,793 stops, none abroad.
- **Serbia** (data.gov.rs): city GTFS only (Belgrade, Niš, Kragujevac, Subotica, Užice). MDB `mdb-1120` "Niš-ekspres" is Niš city; Lasta `mdb-2918` inactive.
- **BiH:** no access point; the state register of international/inter-entity timetables (Official Gazette 7/18) is not published as data.
- **DE/AT:** not verified; no Flix marketplace data found.
- No feed anywhere for Globtour, Croatia Bus, Autotrans/Arriva HR, Lasta, Niš-Ekspres intercity, Autoprevoz Mostar,
  Samoborček, Čazmatrans, Promet Makarska. Operator sites: Promet Makarska uses WordPress admin-ajax; Samoborček search
  runs via getbybus; AK Split publishes HTML + PDF (`/reports/split-polasci.pdf`).

## 5. Bus stations
- **Zagreb (akz.hr)** — best semi-official source: monthly "Prometni očevidnik" PDFs of departures/arrivals (September
  2026: 27 pages, ~22,000 rows, text-extractable with `pdftotext`). Row: register line number (e.g. `HR-BIH-70`), route
  with termini and via points, carrier, scheduled + actual time, days, platform. Covers every carrier at Zagreb incl.
  Flix entities and marketplace partners (768 HR-BIH, 377 HR-SRB, 174 HR-NMK rows). Also a live board fragment
  (`default.aspx?ajax=xmlpolasci`) and ASP.NET search (voznired.akz.hr). robots 404, no explicit licence; operator is
  the public company Zagrebački holding.
- **Belgrade (bas.rs):** 138-URL sitemap, 39 bus line pages; robots disallows `/api`. Not explored further. polazak.rs is a booking SPA.
- **autobusni-kolodvor.com:** aggregates Arriva, Traveling (ex-GetByBus), BusTicket4.me. No clean open data.

## 6. Recommendations / next steps
1. **E-mail Flix** (GIS/open-data team behind gtfs.gis.flix.tech, and partner relations): (i) add marketplace lines to the
   ODbL GTFS or publish a separate feed; (ii) written permission to use `/cms/cities/*/reachable` with attribution.
2. **E-mail AKZ / Zagrebački holding** for permission to re-use the Prometni očevidnik or a structured export.
3. Ask the Croatian NAP and Ministry of Sea, Transport and Infrastructure whether intercity bus operators will publish
   under Regulation (EU) 2017/1926 (MMTIS).
4. Contact Globtour and Croatia Bus directly for GTFS (Li-Bus Livno shows small operators can).
5. **"Routes without timetable" mode** (only with Flix permission): draw city→city links from `reachable` with
   `interconnection:false`, weight by `route_popularity` / `search_volume`, thin each line's clique by `min_duration`
   ordering, coordinates from city-page JSON-LD, weekly snapshot (~12 min for the region at 1 req/s) and diff. Needs a
   "no timetable" flag on routes/corridors and a "reachable, no timetable" list on city click. AKZ register lines
   (termini + via points) could feed the same mode legitimately.
6. Do **not** ship data from Flix `search`/`trip/details` or busticket4.me `/line-details`: technically full
   timetables, but barred by terms / robots.
